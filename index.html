Why static + edge?

Fast by default

Pre-built files are cached on CDN nodes close to visitors, so pages load in milliseconds.

Secure HTTPS

Free, auto-renewing TLS certificates and forced HTTP→HTTPS redirects on every host.

Continuous deployment

Each git push triggers a validated build and an automatic redeploy.

Deployment pipeline

  1. CommitPush changes to the main branch.
  2. ValidateCI checks that every local asset path resolves.
  3. Build & publishThe host packages the static files.
  4. EdgeFiles propagate to the CDN, served over HTTPS.
